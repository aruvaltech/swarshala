SWARSHALA LOGO KIT
==================
Complete brand identity package — All formats included.

FOLDER STRUCTURE
----------------
/svg    — Vector source files (scalable to any size, ideal for developers)
/png    — High-resolution PNG with transparency (2x retina quality)
/jpeg   — JPEG versions with white background (for print, email)
/webp   — WebP format (modern web — smaller file size, great quality)
/ico    — Favicon ICO (16–256px) + individual PNG sizes for all devices
/pdf    — PDF vector export (for print, Figma, Illustrator import)
